textkit splits text into tokens with a [Lexer](/api/textkit/src/index/Lexer/)
and builds on it for [slugify](/api/textkit/src/index/#slugify).

The [API reference](/api/textkit/) is generated from the code's own comments by
`api_docs` — see `ssg.yaml` next to this page.
