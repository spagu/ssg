Shop admin

Sign in to manage products, orders and invoices.

The first sign-in with the bootstrap credentials creates the owner account. Delete SHOP_ADMIN_BOOTSTRAP once you are in.

This panel never holds a download link: they are stored hashed, so a lost one is reissued, never retrieved.
